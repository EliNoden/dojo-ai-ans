---
name: feature
description: Follow the complete flow to create a feature, from the specs definition to the completed and tested implementation.
---

Always use the skill /grill-me first to refine the why, the needs and scope of a requested feature.

The output of it must be a .md file with the following sections : Why, Result, use cases/edge cases, questions/options/decisions.

From the specs file, use the writting-plan skill to generate a plan.

Always launch the implementation of the plan with a brand new agent.

Always follow the project guidelines defined in CLAUDE.md.

Always launch a dedicated agent to execute the testing flow.

At each step, invite the user to check the output to propose changes/fixes.

Always ask questions as a multiple choice UI terminal friendly.
